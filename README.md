# ⚡ 에너지 도시 설계 게임

정해진 예산으로 8×8 지도에 **집, 발전소, 숲**을 배치해서 주민들이 **전기 걱정 없이, 탄소는 적게, 행복하게** 사는 미래도시를 만드는 게임이에요. 초등 4학년 눈높이에 맞췄어요.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 첫 화면 |
| `style.css` | 디자인 |
| `app.js` | 게임 동작 |
| `data.js` | **건물 수치, 미션, 지도(강 위치)** — 선생님이 고쳐 쓰는 파일 |

## 깃허브 페이지로 배포하기

탄소발자국 계산기와 똑같아요.

1. github.com → **+** → **New repository** → 이름(예: `energy-city`), **Public** → **Create repository**
2. **uploading an existing file** → 파일 5개 끌어다 놓기 → **Commit changes**
3. **Settings → Pages** → Branch `main` / `/(root)` → **Save**
4. 1~2분 뒤 주소: `https://내아이디.github.io/energy-city/`

## 게임 방법

1. 미션을 골라요 (🌱 새싹 마을 → 🌿 푸른 도시 → 🌍 탄소 제로 도시, 🎨 자유 설계)
2. 왼쪽에서 건물을 고르고 지도의 빈 땅을 눌러요
3. 오른쪽 상태판에서 돈, 주민, 전기, 탄소, 행복을 확인해요. 🦉 부엉이 박사가 힌트를 줘요
4. **도시 완성! 검사받기**를 누르면 별을 받아요

| 별 | 조건 |
|---|---|
| ⭐ | 주민 목표 채우기 + 전기 부족하지 않기 + 예산 안에서 짓기 |
| ⭐⭐ | + 탄소 목표 이하 |
| ⭐⭐⭐ | + 행복 목표 이상 + 흐린 날에도 전기 충분 |

### 배울 수 있는 것 (숨은 규칙)

- **석탄 발전소**는 전기를 많이 만들지만 탄소가 가장 많고, 집 옆에 있으면 주민이 싫어해요
- **태양광·풍력**은 탄소가 없지만 흐린 날에는 절반만 만들어요 → **전기 저장소**나 **수력**이 필요해요
- **풍력**은 지도 가장자리(바람이 센 곳)에서 전기를 더 만들어요
- **수력**은 강 옆에만 지을 수 있어요
- **숲·공원**은 집 옆에 있으면 주민이 더 행복해요
- **공장**은 돈을 벌어 오지만 탄소가 나와요 → 돈과 환경 사이에서 고민하게 돼요
- 사람이 많아질수록 행복이 조금씩 줄어요 → 학교와 공원이 필요해요

## 수업에서 쓰는 방법

- **개인·짝 활동**: 태블릿으로 각자 미션에 도전해요. 도시는 그 기기에 자동 저장돼요.
- **발표·비교**: 결과 창의 **도시 코드**를 복사해서 선생님께 보내요. 선생님 컴퓨터 첫 화면의 **친구 도시 코드 불러오기**에 붙여 넣으면 그 도시가 그대로 열려서 전자칠판에 띄우고 발표할 수 있어요.
- **토론 질문 예시**: "석탄 발전소를 안 쓰고 전기를 채우려면 왜 돈이 더 들까?", "흐린 날을 대비하려면 어떻게 해야 할까?"

## 난이도 고치기

`data.js`에서 숫자를 바꾸면 돼요.

- 건물 값, 전기, 탄소, 행복: `EC_TILES`
- 미션 예산과 목표: `EC_MISSIONS`
- 강 위치: `EC_MAP.river` (행, 열)

※ 강 위치나 건물 코드를 바꾸면 예전에 만든 도시 코드는 안 열릴 수 있어요.
